# Python Fundamentals — Solved Exercises (Task 1.1)

Beginner-level exercise set covering the core Python you need before touching ML:
variables, control flow, containers, functions, file handling, exceptions, and OOP.

## Files

| File | Topic |
|------|-------|
| `01_variables_basics.py` | Variables, numeric/string types, f-strings, `type()` |
| `02_lists_and_tuples.py` | Lists, tuples, slicing, comprehensions |
| `03_dictionaries_and_sets.py` | Dicts, nested structures, set operations |
| `04_conditionals_and_loops.py` | `if`/`elif`/`else`, `for`, `while` |
| `05_functions.py` | Functions, `*args`/`**kwargs`, lambdas, closures |
| `06_file_handling.py` | Text/CSV/JSON I/O, context managers |
| `07_exceptions.py` | `try`/`except`/`else`/`finally`, custom exceptions |
| `08_oop.py` | Classes, inheritance, dunder methods, polymorphism |

## How to run

```bash
python 01_variables_basics.py    # run a single exercise
python run_all.py                # run the whole set
```

Every file is self-contained, prints its results, and asserts expected answers,
so a clean exit means the solutions are correct.
